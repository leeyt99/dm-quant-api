二、DM Python SDK 安装与参数说明
1．SDK 简介
• 本 SDK 的 Python 包名为 dm_quant_api_client，用于调用需要 SM4 加密的量化
API 接口。
• SDK 当前具备以下能力：
￮ 自动完成请求报文的 SM4 加密和响应解密
￮ 统一封装 HTTP 请求头、超时、证书校验等通用逻辑
￮ 支持将接口返回结果默认转换为 pandas.DataFrame
￮ 支持请求参数和响应字段在驼峰命名与下划线命名之间自动转换
• 运行环境要求：
￮ Python 3.8 及以上
• 依赖包：
￮ requests>=2.25.0
￮ pandas>=1.0.0
￮ gmssl>=3.2.0
2．安装说明
可通过链接下载 python 包，链接：http://dm-download.oss-cn-
shanghai.aliyuncs.com/dm_api_client/python/0.2.3/dm_quant_api_client-
0.2.3-py3-none-any.whl
指定本地文件路径安装 python 包：pip install /your_path/dm_quant_api_client-0.2.3-
===== PAGE 8 =====
py3-none-any.whl
3．快速开始
3.1 最小示例
Python
from dm_quant_api_client import DMQuantApiClient
client = DMQuantApiClient(
app_key="YOUR_APP_KEY",
app_secret="YOUR_APP_SECRET",
pythonic=True,
)
result = client.post_data(
data={
"security_id_list": ["500426.SZ", "500427.SZ"],
},
api_path="/dm-quant-func-service/api/v1/bond/basic-info/info",
)
print(result)
说明：
• 使用参数，pythonic=True ，post_data(...) 默认返回 pandas.DataFrame

6．参数风格说明
SDK 支持对请求和响应字段名进行统一转换。
6.1 推荐使用方式
如果客户希望在 Python 代码中统一使用下划线命名，建议开启 pythonic=True：
Python
client = DMQuantApiClient(
app_key="YOUR_APP_KEY",
app_secret="YOUR_APP_SECRET",
pythonic=True
)
开启后实际效果为：
• 请求参数中的 python 风格(snake_case) 字段会自动转换为接口常用的 驼峰风格
(camelCase)
• 返回结果中的 驼峰风格(camelCase) 字段会自动转换为 python 风格(snake_case)
如果客户侧代码本身就是按接口文档中的驼峰字段编写，可不使用 pythonic 参数，此
时请求字段和返回字段都不会被自动修改。
Python
client = DMQuantApiClient(
app_key="YOUR_APP_KEY",
app_secret="YOUR_APP_SECRET",
)

===== PAGE 12 =====

四、常见问题与注意事项
1．初始化时报 `app_key is required`
原因：
• 未显式传入 app_key
• 也未设置环境变量 INNO_APP_KEY
处理建议：
• 检查初始化代码是否传入了 app_key
• 或确认运行环境中已设置 INNO_APP_KEY
2．初始化时报 `app_secret is required`
原因：
• 未显式传入 app_secret
• 也未设置环境变量 INNO_APP_SECRET
处理建议：
• 检查初始化代码是否传入了 app_secret
• 或确认运行环境中已设置 INNO_APP_SECRET
3．请求返回 HTTP 非 200
SDK 会抛出 HttpStatusError。
处理建议：
• 检查 api_path 是否正确
• 检查网络连通性、网关权限和证书配置

4．返回结果无法解密或不是合法 JSON
SDK 可能抛出：
• CryptoError
• ResponseDecodeError
处理建议：
• 确认 app_secret 是否正确
• 确认服务端返回是否为约定的加密响应格式
• 确认接口是否已接入正确的网关和环境
5．返回 `DataFrame` 转换失败
当 return_type="dataframe" 时，SDK 会尝试把返回结果转换为 pandas.DataFrame。
如果接口返回结构不适合表格化处理，可能会报错。
处理建议：
• 确认接口返回是否为列表、data/columns 结构或普通字典
6．返回“无订阅套餐”
该场景表示您暂无函数调用权限。
处理建议：
• 可联系客户经理
7．返回“额度已耗尽”/”限流“等提示
该场景表示您的流量已达上限。
处理建议：
• 可根据 field_names 字段筛选业务需要的字段出参
